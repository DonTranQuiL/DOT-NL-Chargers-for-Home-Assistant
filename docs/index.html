Dutch public EV chargers

Charge points, one poll.

A Home Assistant integration for occupancy, connectors, and tariffs from NDW DOT-NL. One request per cycle, map pins you can cap, and a cheapest-price sensor that ignores placeholder zeros.

Install with HACS Latest release

What it tracks

Live GeoJSON around your home. Sensors only render what the coordinator already fetched.

Occupancy

Available stations, occupied stations, free connectors, and totals. Closest available station is its own sensor, in kilometres.

Energy price

Cheapest EUR/kWh from OCPI energy tariffs, cached for hours. A 0.0 component next to a real rate is ignored unless the station is actually free.

One request

The poll is a single GeoJSON call. Tariff enrichment runs in the background. If the feed fails, the last good payload stays on screen.

Map pins you can cap

Each station inside Maximum map markers is a pin. Drop the number from 30 to 8 and the extras are deleted, not left unavailable. The ones you keep stay on the map.

  • Green, a free charger
  • Amber, partly free
  • Red, full
  • Gray, unknown

Installation

HACS custom repository, then a restart.

HACS

  1. 1. HACS, Integrations, then the menu, Custom repositories.
  2. 2. URL https://github.com/DonTranQuiL/DOT-NL-Chargers-for-Home-Assistant
  3. 3. Category Integration, then Add.
  4. 4. Download DOT-NL Chargers and restart Home Assistant.
  5. 5. Settings, Devices and services, Add integration, DOT-NL Chargers.

Keep the recorder lean

The overview sensor carries the station list. Exclude it so Home Assistant does not write that blob into the database.

recorder:
  exclude:
    entities:
      - sensor.dot_nl_chargers_overview

Lovelace card

Copy dotnl_chargers-card.js into /config/www/ and add it as a JavaScript module at /local/dotnl_chargers-card.js.

type: custom:dotnl_chargers-card
entity: sensor.dot_nl_chargers_overview
title: Chargers near home
